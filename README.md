# IT Help Desk Ticketing System

A web application designed for campus IT offices to log, assign, track, and resolve IT service tickets efficiently.

## Project Structure
- \index.html\: Core HTML interface
- \css/style.css\: Custom styling (dark theme)
- \js/app.js\: Core application logic and state machine
- \docs/\: Requirements analysis, prompt logs, and screenshots

## How to Run
1. Clone this repository to your local machine.
2. Open \index.html\ directly in any modern Web Browser.
